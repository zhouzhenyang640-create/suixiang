# 随想 · 私人聊天室

一个移动端优先的 PWA：用聊天消息的方式记录不同话题的想法。纯静态前端，无账号、无后端、无第三方依赖。

## 功能

- 多个独立对话：新建、重命名、更换图标、置顶、删除、单个对话 TXT 导出
- 文字消息：多行输入、编辑、复制、收藏、移入回收站、恢复或彻底删除
- 图片消息：从手机相册/文件选择图片，保存在本地数据库
- 全局搜索：搜索所有对话名称和文字消息，可跳转回原消息
- 深色、浅色、跟随系统三种主题
- JSON 完整备份和恢复，包含图片
- IndexedDB 本地持久化，Service Worker 缓存应用文件，支持离线打开

## 重要说明

1. 应用内容保存在当前浏览器的 IndexedDB 中。没有账号、云同步或聊天服务器，作者无法读取你的记录。
2. 请定期导出 JSON 备份。清除浏览器网站数据、卸载/重置浏览器或更换设备，都可能导致本地记录丢失。
3. 图片会增加备份文件体积。JSON 备份会把图片转换为 Data URL，图片较多时文件可能很大。
4. PWA 安装和 Service Worker 离线缓存需要 HTTPS（或开发时使用 localhost）。直接双击 `index.html` 通常不能安装为 PWA。
5. 删除整个对话会同时删除其中的消息；消息回收站只处理单条消息。删除整个对话前建议先导出 TXT 或完整 JSON。
